# HinduGuide

This is a sample iOS app that provides a chat-based guide for exploring concepts of Hinduism. It includes:

- **Chat and Voice Interaction** using `ChatView` and `VoiceAssistant` for AI-driven conversations.
- **Daily Verse Notifications** using `NotificationManager` to send local notifications with selected verses.
- **SwiftUI Interface** for quick prototyping.

This code serves as a starting point and requires integration with an actual LLM service to deliver in-depth Hinduism guidance. Voice recognition uses `Speech` framework and text-to-speech is built into `ChatView`.
